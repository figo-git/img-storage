# 备忘录日历图片存储目录

本文件夹用于存放备忘录网页上传的所有图片文件，配套仓库为 `img-storage`。

## 文件规则

1. 图片命名格式：`img_时间戳.jpg`，由网页上传程序自动生成，请勿手动修改文件名。
2. 所有图片通过 jsDelivr CDN 加速访问，外链格式：

   ```
   https://cdn.jsdelivr.net/gh/figo-git/img-storage@main/images/图片文件名.jpg
   ```

## 注意事项

1. 仓库为公开仓库，所有图片外链任何人可访问，请勿上传身份证、证件、隐私照片。
2. 图片统一自动压缩，长边最大 1200px，质量 70%，减少存储空间占用。
3. 不建议手动批量删除图片：删除后备忘内对应的图片链接会失效，页面无法加载图片。
4. 免费 LFS 存储仅 10GB，大量原图建议本地备份后再上传。

## 配套项目

- 备忘录日历网页仓库：`figo-git/db-gist1`
- 数据存储：Secret Gist `memos.json`
